# Levi Lowe — Academic Website

Personal website of **Levi Lowe**, Ph.D. candidate in philosophy at the University of Utah —
philosophy of science, bioethics, and the philosophy of psychiatry, with research on addiction,
rationality, and decision theory.

Plain, static HTML/CSS with no build step.

## Run locally

```bash
python3 -m http.server 8137
# then open http://localhost:8137
```

Or just open `index.html` in a browser.

## Structure

| File | Purpose |
| --- | --- |
| `index.html` | Home |
| `research.html` | Research & dissertation |
| `teaching.html` | Teaching |
| `cv.html` | Curriculum vitae |
| `styles.css` | Shared design system |
| `assets/` | CV, teaching portfolio, writing sample (PDF), headshot |

Deployed with GitHub Pages.
